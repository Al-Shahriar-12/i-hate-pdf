Files and security

ZIP archives, checksums and metadata removal.

  • Remove PDF metadata: Strip the author, title, software and XMP details hidden in a PDF.
  • Remove photo metadata: Strip EXIF, GPS location and camera details from photos without losing quality.
  • Hash generator: Create SHA-256, SHA-384, SHA-512 and SHA-1 checksums for text or files, and compare them.
  • Create ZIP: Bundle files into a single ZIP archive.
  • Open ZIP: Look inside a ZIP and save the files you need, with safety checks.
  • Protect PDF: Add a password to a PDF with strong AES-256 encryption.
  • Unlock PDF: Remove the password from a PDF you’re allowed to open, so other tools can work with it.
  • Password generator: Create strong random passwords with your browser’s secure random generator.
  • File inspector: See a file’s real type, size, dimensions, page count and SHA-256.
