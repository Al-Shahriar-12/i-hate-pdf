Developer tools

Format JSON, encode, hash and generate IDs.

  • Image to Base64: Encode an image as a Base64 data URI for HTML, CSS or JSON.
  • JSON formatter: Format, validate and minify JSON, with exact error positions.
  • Base64 encode/decode: Encode text to Base64 or decode it back, with full Unicode support.
  • URL encode/decode: Percent-encode text for URLs, or decode encoded URLs.
  • Hash generator: Create SHA-256, SHA-384, SHA-512 and SHA-1 checksums for text or files, and compare them.
  • UUID generator: Generate random version 4 UUIDs using your browser’s secure random generator.
  • Unix timestamp converter: Convert Unix timestamps to dates and back, in local time and UTC.
  • Favicon generator: Turn a logo into favicon.ico plus every PNG icon size a website or PWA needs.
  • Colour converter: Convert colours between HEX, RGB, HSL and CMYK, and check text contrast.
  • Base64 to image: Turn a Base64 string or data URI back into an image you can save.
  • CSV ⇄ JSON: Convert CSV to JSON and JSON to CSV, with quotes, commas and nested fields handled.
  • JSON ⇄ YAML: Convert between JSON and YAML, and validate both.
  • Markdown to HTML: Write Markdown, see a live preview, and export clean HTML.
  • Regex tester: Test regular expressions with highlighted matches, groups and replace.
  • JWT decoder: Decode a JSON Web Token’s header and payload and check its expiry.
  • Text compare: Compare two texts and see exactly what was added and removed.
  • Password generator: Create strong random passwords with your browser’s secure random generator.
  • HTML entities: Escape text for HTML, or turn entities like &amp;amp; back into characters.
  • Number base converter: Convert between binary, octal, decimal and hexadecimal, any size.
  • Python runner: Run Python 3 in your browser, with NumPy, SymPy, pandas and Matplotlib on demand.
