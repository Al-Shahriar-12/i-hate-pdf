Text tools

Count, clean up and reshape text in any language.

  • PDF to text: Pull the text out of a PDF so you can copy, edit or search it.
  • Word counter: Count words, characters, sentences and reading time, including Bengali text.
  • Case converter: Switch text between UPPER, lower, Title, Sentence, camelCase, snake_case and more.
  • Bengali digit converter: Convert numbers between English digits (0–9) and Bengali digits (০–৯).
  • AI writing assistant: Rewrite, fix grammar, shorten, change tone, turn notes into an email, or translate between English and বাংলা.
  • Markdown to HTML: Write Markdown, see a live preview, and export clean HTML.
  • Text compare: Compare two texts and see exactly what was added and removed.
  • Bijoy to Unicode: Convert old Bijoy (SutonnyMJ) Bangla text or Word files to Unicode বাংলা.
  • Lorem ipsum generator: Generate placeholder paragraphs, sentences or words.
  • Text cleaner: Remove duplicate or empty lines, trim spaces and sort lines.
  • Unicode to Bijoy: Convert Unicode Bengali into Bijoy (SutonnyMJ) text for older software.
